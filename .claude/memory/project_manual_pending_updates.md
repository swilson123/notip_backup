## Pending updates to fold into the manual

- **Obstacle-avoidance voice narration** (added 2026-06-04, code done, manual NOT yet updated).
  The rover now speaks the avoidance steps as it maneuvers, implemented in
  `lib/mission/avoid_object.js` via an `announce(line, key, urgent)` helper (deduped by a
  `last_voice_key` so each step speaks once):
  - "Object detected. Spinning {right|left} {X} degrees." — X ≈ angle to the chosen green
    LiDAR zone's center. **Urgent** (interrupts current speech).
  - "Object detected. Path blocked, holding." — when no clear zone exists. **Urgent**.
  - "Spinning {dir} {X} degrees." — on re-evaluation mid-avoidance. Queued.
  - "Crawling forward 1 meter." — creep distance = `CREEP_CLEARANCE_DISTANCE_M` (1 m). Queued.
  - "Path clear. Resuming mission." — in `resume_mission()`. Queued.
  Also: `lib/navigation/run_mission.js` guards its old fallback `say_event('object_detected')`
  so it won't double-announce while LiDAR avoidance is actively maneuvering.
